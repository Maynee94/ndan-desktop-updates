# NDAN Creator Desktop — bản cập nhật

Repository phân phối công khai cho bộ cài Windows và dữ liệu cập nhật của NDAN Creator Desktop. Không lưu cây mã nguồn ứng dụng, API key, cookie hoặc dữ liệu người dùng tại đây.

## Tải ứng dụng

Mở [Releases](https://github.com/Maynee94/ndan-desktop-updates/releases) và tải `Setup.exe` để cài đặt và nhận cập nhật trong app. Bản Portable chạy trực tiếp nhưng không hỗ trợ cập nhật tích hợp.

## Chuyển tiếp 3.4.3

Bản 3.4.3 đổi địa chỉ cập nhật sang repository này. Nếu đang dùng Setup 3.4.2, hãy kiểm tra cập nhật trong app khi repository mã nguồn cũ còn Public. Sau khi đã chạy 3.4.3, app sẽ đọc bản mới từ nơi này.

## Nội dung Release

Chỉ phát hành `.exe`, `.blockmap` và `latest.yml`. Không tải ZIP mã nguồn, AppData, khóa API hoặc phiên đăng nhập lên Releases.

Các bản vá mới được build/kiểm thử trong repo nguồn và xuất bản qua token riêng chỉ có quyền ghi vào repo cập nhật này. Workflow import ở đây phục vụ bản chuyển tiếp 3.4.3; không đọc mã nguồn Private.
